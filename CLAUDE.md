# catfinderapp.com

Sitio estático de CatFinder (español en la raíz, inglés en `en/`), publicado con GitHub Pages desde `main` del repositorio `gatitenApp/catfinderapp.com`, detrás de Cloudflare.

Proyecto en Meow Planning: CATF

- No borrar ni editar `CNAME` (`www.catfinderapp.com`): conecta el dominio.
- Repositorio público: nunca subir claves, tokens ni archivos `.env`.
